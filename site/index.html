Your library. Your server. Your books.

Trove is a free, open-source, self-hosted library server for ebooks, comics and audiobooks. Run it on your own server or NAS to organise your collection, read in any browser, and sync to Kobo, KOReader and OPDS reading apps, with no third-party service involved.

What Trove does

Every format in one place

EPUB, PDF, MOBI, AZW3, FB2, comics (CBZ, CBR, CB7) and audiobooks (M4B, M4A, MP3, Opus), in libraries that can live on local disks or a NAS share.

Read in the browser

A built-in reader for books, comics, PDFs and audiobooks, with highlights, notes, bookmarks and reading progress.

Sync your devices

Kobo sync, KOReader progress sync, an OPDS catalogue for reading apps, and a Komga-compatible API for comic readers.

Automatic metadata

Covers, descriptions, series and ratings from Google Books, Open Library, Amazon, Goodreads and more, all editable.

Shelves that sort themselves

Custom shelves, rule-based Magic Shelves, series and author pages, filters and full-text search.

For the whole household

Separate shelves, progress and preferences per user, library access controls and content restrictions, with local accounts or OIDC single sign-on.

Hands-off importing

BookDrop watches a folder, identifies new files, fetches their metadata and queues them for import.

Share and send

Send any book to a Kindle or an email address in one click.

Install

With Docker, use the ghcr.io/x2-consult/trove image and the example compose file. On an Ubuntu or Debian server, the native installer sets up everything, including PostgreSQL, a systemd service and an optional HTTPS reverse proxy:

git clone -b master https://github.com/X2-Consult/trove.git
cd trove
./install.sh

See Installation for both methods.

Questions

Is Trove free?
Yes. Trove is open source under the GNU AGPL v3 licence, with no paid tier, and you host it yourself.
How does Trove relate to BookLore?
Trove started as a fork of BookLore after BookLore's maintainer abandoned it, and is maintained independently. It uses PostgreSQL, adds a native (non-Docker) installer, hardens security and fixes memory use. Existing BookLore installs can move to Trove and keep their libraries, users, reading progress and paired Kobo and KOReader devices.
Is it an alternative to Calibre-Web, Kavita or Komga?
Trove covers the same ground: a self-hosted web library and reader for ebooks and comics, with OPDS, device sync and multiple users, and it adds audiobooks and a Komga-compatible API in the same app.
Does it work with Kobo and Kindle?
Kobo e-readers sync directly with Trove, including reading progress. Kindles can receive books by email through Send to Kindle. KOReader devices sync reading progress, and any OPDS app can browse and download books.
What does it run on?
Any Linux server, NAS or home lab that runs Docker or Podman (a Helm chart is included for Kubernetes), or natively on Ubuntu and Debian with Java 25 and PostgreSQL.

LubimyCzytac

LubimyCzytac is Poland's largest book rating and review platform, often called the "Polish Goodreads." It's the best source for metadata on Polish literature and Polish translations, covering titles, authors, descriptions, ratings, series information, ISBNs, and cover images that may not exist on English-language platforms.

No Setup Required

LubimyCzytac doesn't need API tokens, cookies, or any authentication. Switch it on under Metadata Providers in Settings › Metadata 1, and give it a priority in Settings › Metadata 2.

Enabling LubimyCzytac

Open Settings › Metadata 1, find Lubimyczytac under Ready-to-Use Providers, switch it on, and click Save Configurations.

Using It in Metadata Fetch

Once enabled, LubimyCzytac appears as a choice in the priority columns of Library metadata (Settings › Metadata 2) and in the Custom Fetch dialog. You can set it as Priority 1, 2, 3, or 4 for any individual field.

For Polish books or Polish translations, set LubimyCzytac as Priority 1 for most fields and use Google Books or Goodreads as fallbacks. For English books, keep it as Priority 3 or 4 behind providers like Amazon or Google. If LubimyCzytac doesn't have data for a particular field, Trove automatically tries the next provider in your priority list.

What You Get

LubimyCzytac provides the standard set of metadata fields: title, authors, description, cover image, publisher, published date, page count, language, ISBN-10, ISBN-13, categories, tags, series name, and series number.

It also returns two provider-specific fields:

FieldDescription
LubimyCzytac IDUnique identifier linking to the book's page on lubimyczytac.pl. Shown as a clickable link in the metadata viewer.
LubimyCzytac RatingCommunity rating from Polish readers. Displayed with the site's favicon in the metadata viewer.

Both fields can be locked in the metadata picker to prevent overwriting during future refreshes.

Rating Scale

LubimyCzytac uses a 10-point scale. Trove automatically converts it to 5 points for consistency with other providers (e.g., an 8.0 becomes 4.0).

Troubleshooting

ProblemWhat to check
No results returnedMake sure the provider is switched on in Settings › Metadata 1 and has a priority in Metadata 2. Verify the book exists on lubimyczytac.pl by searching manually.
Wrong book matchedUse title + author name for the most accurate results. For Polish books, searching with the Polish title gives the highest accuracy.
Missing fieldsNot every book has complete metadata. LubimyCzytac coverage is strongest for Polish literature and weakest for niche English-only titles.
Network errorsConfirm your Trove instance can reach lubimyczytac.pl (check firewalls, DNS, and proxy settings).

Web Scraping

LubimyCzytac doesn't provide a public API, so Trove uses web scraping. This is reliable but may occasionally break if the LubimyCzytac website structure changes. If metadata fetching suddenly stops working for this provider, check for a Trove update.

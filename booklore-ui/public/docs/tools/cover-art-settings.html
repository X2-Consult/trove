Cover settings

Where covers come from, how odd-shaped ones are trimmed, and how to redo covers for many books at once.

Where covers come from

  • The book file. When a book is scanned, Trove uses the cover inside it: an EPUB's cover image, the first page of a PDF or comic, an audiobook's embedded artwork.
  • Metadata sources. Fetching metadata can bring a cover from Amazon, Google Books, Open Library and others, if Update Covers is on in Library metadata.
  • You. On a book's Edit Metadata tab you can upload an image or search the web for one. Lock the cover to keep it.
  • Generated. Generate Custom Cover (in a book's Metadata menu) makes a plain cover showing the title and author, handy for books with no cover at all.

Trimming tall or wide covers

In Settings › Application, under Book Cover Image. Web comics and some scans have a first page far taller (or wider) than a book cover, which looks wrong as a thumbnail.

SettingWhat it does
Vertical Cover CroppingTrims very tall images from the top to a cover shape
Horizontal Cover CroppingTrims very wide images from the left
Aspect Ratio ThresholdHow out of proportion an image must be before it's trimmed (2.5 means two and a half times taller or wider than normal)
Smart CroppingSkips plain borders and margins so the trimmed cover shows the picture, not blank edge

The settings apply to covers made from now on. To apply them to existing books, use Regenerate Covers on the same page. See Application settings.

Redoing many covers at once

Select books in the grid or table, open the selection bar's metadata menu, and choose:

  • Regenerate Covers: take the cover from each file again
  • Generate Custom Covers: make title-and-author covers

For a single book, the same options are in its Metadata menu (Regenerate Cover (File) and Generate Custom Cover).
